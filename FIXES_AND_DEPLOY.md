# Исправления PinPosy

## Что изменено

- `backend/index.js`: онбординг больше не пытается записать `website_url` в таблицу `users`; URL сохраняется в `projects`. Если проект уже существует, данные из онбординга обновляют его, а не теряются. В лог сервера добавлены коды и сообщения ошибок Supabase для диагностики.
- `db/migrations/004_onboarding.sql`: миграция синхронизирует допустимые тарифы с `analytics`, `start`, `pro`, `agency`, переносит старое значение `standard` в `pro` и допускает повторный запуск.
- `frontend/src/components/onboarding/OnboardingWizard.tsx`: уточнён текст об оплате — выбор тарифа не выдаёт платную подписку, пока платёжная интеграция не подключена.
- Удалён неиспользуемый `AuthModal.tsx`, который ссылался на пять методов авторизации, отсутствующих в текущем `AuthContext`, и из-за этого ломал проверку TypeScript.

## Обязательные шаги после загрузки

1. В Supabase откройте **SQL Editor** и выполните содержимое `db/migrations/004_onboarding.sql`. Это необходимо, если в таблице `users` ещё нет `onboarded` и `tariff_plan` либо осталось старое ограничение тарифов.
2. Разверните обновлённый backend на Render и обновлённый frontend на Vercel.
3. Войдите в приложение и пройдите онбординг с пустым URL, затем с валидным `https://` URL. Проверьте, что запрос `PATCH /me/onboarding` отвечает `200` и в таблице `projects` сохранён URL.
4. Если ответ всё ещё `500`, посмотрите логи backend на Render: теперь сообщения `[onboarding]` включают исходную ошибку Supabase. Не публикуйте JWT, пароли, ключи API или переменные окружения в обращениях за помощью.

## Проверки

- `node --check backend/index.js` — пройдено.
- `npm run lint` в `frontend` — пройдено после устранения ссылок на отсутствующие свойства `AuthContextType`.
- `git diff --check` — пройдено.
- `npm run build` в предоставленной среде не удалось завершить: в распакованном `node_modules` отсутствует нативный optional binding для `rolldown` (`@rolldown/binding-linux-x64-gnu`). Это проблема комплектации зависимостей среды, а не сообщение об ошибке исходного кода. Архив не содержит `node_modules`; установите зависимости заново через `npm ci` перед сборкой.

## Ограничение оплаты

Экран оплаты пока является заглушкой. Не включайте платные возможности только по выбранному пользователем тарифу. Для настоящей подписки требуется подключить платёжного провайдера и менять доступ только после подтверждённого webhook.
