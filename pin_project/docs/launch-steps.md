## ШАГ 1. Обновить код на GitHub (Вы, ~10 минут)

В песочнице нет доступа к вашему GitHub, поэтому финальный пуш — за вами.

1. Скачайте архив **`pinposy-updated-src.zip`** (приложен к сообщению и лежит в AI Drive `/APP/`).
2. Распакуйте — внутри папка `project/` со структурой:
   ```
   project/
   ├── backend/          ← серверная часть (обновлена: безопасность Этапа 3)
   ├── frontend/         ← сайт (обновлён: PinPosy, регистрация, документы)
   ├── docs/             ← пакет для Pinterest + инструкции
   ├── planning.md       ← план с журналом
   └── README.md
   ```
3. В вашей локальной копии репозитория (где `git clone https://github.com/Diana-866/pinboard-ai.git`)
   **замените** папки `backend/`, `frontend/`, `docs/` и файлы `planning.md`, `README.md` на новые из архива.
   (Старую папку `frontend/dist/` можно удалить — она пересоберётся сама.)
4. Откройте терминал в папке репозитория и выполните:
   ```bash
   git add -A
   git commit -m "Rebrand to PinPosy, domain pinposy.com, security hardening, Pinterest submission package"
   git push origin main
   ```
5. Vercel и Render заберут код с GitHub автоматически (автодеплой уже настроен).

⚠️ Ничего не теряется из старого кода: вы заменяете файлы поверх, история git сохраняется.

## ШАГ 2. DNS-записи в Beget (Вы, ~10 минут + ожидание)

Панель Beget → **Домены** → DNS-менеджер `pinposy.com`:

1. **Удалите** записи парковки Beget (A-запись на 5.101.x.x и похожие).
2. **Добавьте** три записи (подробно — `docs/domain-setup.md`):

   | Тип | Имя | Значение |
   |---|---|---|
   | A | `@` | `76.76.21.21` |
   | CNAME | `www` | `cname.vercel-dns.com.` |
   | CNAME | `api` | `pinboard-ai-backend.onrender.com.` |

3. Ждите 10 минут – 4 часа (обычно ~30 минут).

## ШАГ 3. Привязать домены в Vercel и Render (Вы, по 3 минуты)

**Vercel** (фронтенд): Settings → Domains → Add → `pinposy.com`, затем `www.pinposy.com`.
**Render** (бэкенд): Settings → Custom Domains → Add → `api.pinposy.com`.

HTTPS включится сам — именно после этого замок 🔒 заменит «Не защищено» с вашей заглушки Beget.

## ШАГ 4. Переменные окружения (Вы, ~5 минут)

После «Valid» в Vercel и «Verified» в Render:

| Где | Переменная | Значение |
|---|---|---|
| Render | `FRONTEND_URL` | `https://pinposy.com` |
| Vercel | `VITE_API_URL` | `https://api.pinposy.com` |

Vercel после добавления переменной — сделайте Redeploy.

## ШАГ 5. Проверить (Вы + Агент, ~10 минут)

Пройдите чек-лист из `docs/domain-setup.md` (шаг 5): сайт с замком, `/health`, вход, документы.
Если что-то не работает — напишите мне, разберём.

## ШАГ 6. Заявка в Pinterest API (Вы, ~30 минут)
