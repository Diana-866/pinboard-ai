# Привязка pinposy.com — DNS и HTTPS

> Домен куплен у **Beget** 2026-10-18. HTTPS «защищено» появится АВТОМАТИЧЕСКИ после шагов ниже —
> сертификаты бесплатно выпускают Vercel и Render сами, вручную ничего устанавливать не нужно.
> Сейчас видно «Не защищено» и страницу-заглушку Beget, потому что домен пока никуда не привязан.

## Шаг 1. DNS-записи в Beget

Панель Beget → раздел **«Домены»** → напротив `pinposy.com` откройте **DNS-менеджер** (иконка со стрелками).

Удалите записи парковки Beget (обычно `A @ → 5.101.153.x` и/или `CNAME` на beget-адрес) и добавьте три записи:

| Тип | Имя (поддомен) | Значение | Стандартный TTL |
|---|---|---|---|
| `A` | `@` (без поддомена) | `76.76.21.21` | 600 |
| `CNAME` | `www` | `cname.vercel-dns.com.` | 600 |
| `CNAME` | `api` | `pinboard-ai-backend.onrender.com.` | 600 |

Точные значения Vercel/Render показывают на своих шагах (2 и 3) — если отличаются, вводите их.

## Шаг 2. Подключить фронтенд к Vercel

1. Vercel → проект → **Settings → Domains → Add** → `pinposy.com`.
2. Так же добавьте `www.pinposy.com` (Vercel предложит редирект на основной — согласиться).
3. Статус должен смениться с «Invalid Configuration» на «Valid» после того, как DNS-записи из шага 1 обновятся (10 мин – 4 ч).
4. Сертификат HTTPS Vercel выпустит сам — замок в браузере появится без ваших действий.

## Шаг 3. Подключить бэкенд к Render

1. Render → сервис → **Settings → Custom Domains → Add Custom Domain** → `api.pinposy.com`.
2. Если CNAME `api` из шага 1 уже добавлен — статус станет «Verified», сертификат выпустится сам.

## Шаг 4. Переменные окружения (после того как домены заработают)

| Где | Переменная | Значение |
|---|---|---|
| Render (бэкенд) | `FRONTEND_URL` | `https://pinposy.com` |
| Vercel (фронтенд) | `VITE_API_URL` | `https://api.pinposy.com` |

В Vercel: Settings → Environment Variables → добавить → **Redeploy** проекта.
В Render: Environment → сохранить → сервис перезапустится сам.

## Шаг 5. Проверка (все пункты — только затем заявка)

- [ ] `https://pinposy.com` открывается, замок 🔒 зелёный, редирект с `www` работает
- [ ] `https://api.pinposy.com/health` отвечает `{"ok":true}`
- [ ] Регистрация/вход работают с нового адреса
- [ ] `/privacy` и `/terms` открываются
- [ ] Генерация досок/пинов работает (если есть кредиты)
- [ ] Заявка в Pinterest — по `docs/pinterest/submission-checklist.md`

## Почему заявке Pinterest это безопасно

Публичные адреса — `pinposy.com` и `api.pinposy.com` — больше не меняются никогда. Переезд на российские
серверы (Этап 1Б) = смена DNS-целей при тех же адресах: заявка, пользователь и Pinterest ничего не заметят.
