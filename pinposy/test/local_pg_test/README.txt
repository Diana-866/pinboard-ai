# Локальный тест миграций (не является частью миграций PinPosy)

Файлы stub_002…stub_008 — это ЗАГЛУШКИ для прогона цепочки миграций на локальном PostgreSQL.
Они имитируют содержание реальных миграций 002–008 ПО ОПИСАНИЮ владельца (репозиторий приватный).
НИ В КОЕМ СЛУЧАЕ не копировать их в db/migrations/ и не запускать на рабочей базе Supabase.
Реальные 002–008 применяются из db/migrations/ как есть.
