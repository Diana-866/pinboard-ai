# AUD-250 — Лимит описания пина в редакторе

**Дата:** 2026-11-09  
**Файл:** `frontend/src/components/pins/PinGenerator.tsx`

## Что было не так

Редактор показывал счётчик `N / 500`, а backend endpoint `PATCH /pins/:id` валидирует описание с максимальной длиной 500 символов. При этом textarea не ограничивала ввод. Пользователь мог написать больше 500 символов; сервер отклонял PATCH, хотя интерфейс позволял ввести такой текст.

## Исправление

Добавлен атрибут `maxLength={500}` непосредственно на textarea описания. Клиентский ввод теперь согласован с ограничением backend. Существующие тексты не обрезаются программно; пользователь может продолжить редактирование и сократить старый текст, если он длиннее лимита.

## Пользовательский эффект

Нельзя случайно набрать описание, которое заведомо не сохранится из-за превышения лимита. Счётчик и фактическое ограничение поля теперь соответствуют друг другу.

## Проверка и ограничения

- Статически проверено поле редактора: `maxLength={500}`.
- Статически сверено с backend PATCH: `description` ограничен 500 символами.
- Локальный frontend build, TypeScript и браузерные тесты не запускались.
- CI для нового HEAD ещё требует проверки.
- Production, рабочая БД и деплой не затрагивались.
