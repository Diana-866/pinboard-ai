# AUD-245 — не путать ошибку загрузки Pinterest-досок с пустым аккаунтом (2026-11-09)

## Найдено
В `PinterestCard` ошибка запроса `GET /integrations/pinterest/boards` полностью проглатывалась: компонент очищал список и показывал то же сообщение, что и для аккаунта без досок. При сетевом сбое, временной ошибке Pinterest, rate limit или серверной ошибке пользователь мог решить, что доски удалены/отсутствуют. Не было и явной кнопки повтора именно для ошибки загрузки.

## Исправлено
- Добавлены отдельные состояния `boardsLoading` и `boardsError`.
- Во время запроса показывается индикатор загрузки; пустой список показывается только после успешного ответа с нулём досок.
- Ошибка теперь отображается отдельным alert-блоком с сообщением API и кнопкой повторной синхронизации.
- Сохранена защита от гонок: только самый свежий запрос может обновить доски, ошибку и loading state. Ответ от предыдущего аккаунта не перезапишет текущий экран.
- Ошибка не маскируется под «у вас нет досок».

## Пользовательский эффект
Если Pinterest временно недоступен или сеть оборвалась, пользователь увидит, что загрузка не удалась, а не ложное сообщение об отсутствии досок. Он сможет нажать «Синхронизировать» и повторить загрузку, не переподключая Pinterest.

## Проверки и ограничения
- Статически проверены изменения компонента и сохранение request-id fencing.
- Полный frontend build и component tests в этой среде не запускались: нет локального checkout и зависимостей.
- Production, Pinterest API, deployment и merge не затрагивались.
