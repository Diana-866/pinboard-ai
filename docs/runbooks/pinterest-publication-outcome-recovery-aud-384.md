# Pinterest publication outcome recovery — AUD-384

Если публикация завершилась сообщением о неподтверждённом результате:

1. Не запускайте публикацию повторно автоматически.
2. Откройте журнал публикаций/инструмент сверки и найдите попытку по пользователю, пину, Pinterest-аккаунту и доске.
3. Если удалённый Pinterest Pin ID уже известен, сверяйте его с локальным журналом и историей Pinterest.
4. Повтор разрешайте только после подтверждения, что предыдущий POST не создал пин и запись получила явный безопасный статус.
5. Для HTTP 429 учитывайте Retry-After; повторный POST не отправляется автоматически.

Не трактуйте неизвестный статус, redirect, timeout или 5xx как доказательство отказа Pinterest.
