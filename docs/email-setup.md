# Почта PinPosy: VK WorkSpace + Unisender Go

## Целевая схема

- **VK WorkSpace** — основной ящик поддержки `support@pinposy.com`: входящие письма и ответы из админ-панели.
- **Unisender Go** — автоматические транзакционные письма: подтверждение регистрации, сброс пароля, уведомления об оплате и другие системные сообщения.
- Beget остаётся регистратором домена и DNS-провайдером; почтовый ящик на Beget не используется.

Эта схема разделяет переписку с пользователями и массово/автоматически отправляемые системные сообщения.

## 1. VK WorkSpace: ящик поддержки

Создайте или подключите домен `pinposy.com` в VK WorkSpace и заведите ящик `support@pinposy.com`.

В DNS Beget добавьте MX, SPF, DKIM и другие записи, которые выдаст панель VK WorkSpace. Не используйте старые MX/SPF от Beget или другого почтового сервиса одновременно с новыми записями: следуйте актуальной инструкции VK для домена.

Для подключения внешнего IMAP-клиента может потребоваться отдельный пароль приложения. Используйте адрес ящика как логин. IMAP-сервер, порт и режим шифрования берите из актуальных настроек VK WorkSpace для вашего домена/тарифа; не подставляйте адреса от старых сервисов.

Документация VK:
- [Почта VK WorkSpace](https://biz.mail.ru/docs/saas/mail)
- [Пароль приложения для почтовых клиентов](https://biz.mail.ru/docs/saas/mail)

## 2. Unisender Go: транзакционные письма

Подключите и подтвердите домен отправителя `pinposy.com` в Unisender Go. Добавьте выданные сервисом DNS-записи, включая SPF и DKIM, и дождитесь подтверждения домена.

В настройках SMTP Unisender Go используйте параметры именно вашего аккаунта:
- Host: `smtp.go1.unisender.ru` или `smtp.go2.unisender.ru` — в зависимости от того, где зарегистрирован аккаунт.
- Port: `587` (STARTTLS) или `465` (TLS).
- Username: `user_id` или `project_id` из кабинета Unisender Go.
- Password: API-ключ пользователя или проекта.

Не используйте пароль от ящика VK WorkSpace в настройках Unisender Go.

Официальная документация: [SMTP API Unisender Go](https://godocs.unisender.ru/smtp-api).

## 3. Переменные окружения на Render

Заполните переменные только после того, как оба провайдера настроены и вы получили параметры подключения.

### Входящие письма поддержки (VK WorkSpace / IMAP)

| Переменная | Значение |
|---|---|
| `MAIL_IMAP_HOST` | IMAP-хост, указанный VK WorkSpace для вашего домена |
| `MAIL_IMAP_PORT` | Обычно `993` для SSL/TLS, если это указано в настройках VK |
| `MAIL_IMAP_USER` | `support@pinposy.com` |
| `MAIL_IMAP_PASS` | Пароль приложения для IMAP, если он требуется VK |

### Ответы поддержки из админ-панели (VK WorkSpace / SMTP)

| Переменная | Значение |
|---|---|
| `MAIL_REPLY_SMTP_HOST` | SMTP-хост, указанный VK WorkSpace |
| `MAIL_REPLY_SMTP_PORT` | Обычно `465` для TLS или `587` для STARTTLS, если доступны у VK |
| `MAIL_REPLY_SMTP_USER` | `support@pinposy.com` |
| `MAIL_REPLY_SMTP_PASS` | Пароль приложения/SMTP для VK |
| `MAIL_REPLY_FROM` | `PinPosy <support@pinposy.com>` |

### Автоматические письма (Unisender Go / SMTP)

| Переменная | Значение |
|---|---|
| `MAIL_SMTP_HOST` | `smtp.go1.unisender.ru` или `smtp.go2.unisender.ru` — по аккаунту |
| `MAIL_SMTP_PORT` | `587` (STARTTLS) или `465` (TLS) |
| `MAIL_SMTP_USER` | `user_id` или `project_id` из Unisender Go |
| `MAIL_SMTP_PASS` | API-ключ пользователя или проекта Unisender Go |
| `MAIL_FROM` | Подтверждённый адрес отправителя, например `PinPosy <support@pinposy.com>` |

Не присылайте пароли и API-ключи в чат или GitHub. Добавляйте их только в Environment Variables Render.

## 4. Что поддерживает код

- IMAP читает входящие письма поддержки через отдельные `MAIL_IMAP_*` настройки.
- Ответы из админ-панели отправляются через отдельные `MAIL_REPLY_SMTP_*` настройки.
- Системные письма отправляются через `MAIL_SMTP_*` настройки Unisender Go.
- Старые `MAIL_USER` и `MAIL_PASS` могут использоваться только для прежней конфигурации IMAP/ответов поддержки. Транзакционная отправка требует отдельные `MAIL_SMTP_USER` и `MAIL_SMTP_PASS` и не переключается на ящик поддержки.

## 5. Проверка после настройки

1. Отправьте тестовое письмо с внешнего адреса на `support@pinposy.com`.
2. Убедитесь, что оно отображается во вкладке «Почта» в админ-панели.
3. Ответьте на него из админ-панели и проверьте, что письмо отправлено именно через VK WorkSpace.
4. Запустите тест подтверждения регистрации или сброса пароля и проверьте доставку через Unisender Go.
5. Проверьте SPF/DKIM и папку «Спам» у получателя.

## Юридическая проверка перед production

До включения реальной отправки:
- проверьте фактические регионы обработки и условия обработки данных у обоих почтовых провайдеров;
- обновите RU/EN Privacy Policy: укажите VK WorkSpace и Unisender Go как отдельных получателей/обработчиков данных, цели передачи, категории передаваемых данных и актуальные международные передачи;
- не указывайте провайдеров как уже действующих, пока аккаунты, домен и тестовая доставка не подтверждены.

## Важно

На момент подготовки инструкции провайдеры выбраны как целевая архитектура, но фактические DNS-записи, доменная аутентификация и секреты Render требуют настройки и проверки владельцем аккаунтов. Не считать почтовый канал работающим до прохождения всех проверок выше.
