# Красивая почта support@pinposy.com и ящик в админке

> Цель: вместо `d65gng532k@gmail.com` — красивый адрес **support@pinposy.com** на вашем домене,
> плюс возможность читать входящие и отвечать пользователям прямо из админ-панели PinPosy.

## Шаг 1. Создать ящик на домене (вы, ~15 минут)

Варианты (первый — самый быстрый при вашем регистраторе):

**Вариант А — Beget (домен уже там):**
1. Панель Beget → раздел **«Почта»** → «Создать почту на домене».
2. Ящик: `support@pinposy.com`, надёжный пароль.
3. Beget сам покажет нужные MX/SPF-записи — добавьте их в DNS-менеджере (раздел «Домены» → DNS).
   Обычно это: `MX 10 mx1.beget.com.`, `MX 20 mx2.beget.com.`, `TXT @ "v=spf1 redirect=beget.com"`.

**Вариант Б — Yandex 360 для домена (бесплатный тариф, если доступен):**
1. Регистрируете домен pinposy.com в Yandex 360, создаёте `support@`.
2. DNS: MX `mx.yandex.net.`, TXT `v=spf1 redirect=_spf.yandex.net`.

После настройки проверьте: письмо с gmail на support@pinposy.com должно дойти.

## Шаг 2. Подключить ящик к админке (вы, ~5 минут)

В админке PinPosy появится вкладка «Почта» — входящие письма и ответы. Для её работы добавьте
на Render (Environment) переменные:

| Переменная | Значение (пример для Beget) |
|---|---|
| `MAIL_IMAP_HOST` | `imap.beget.com` (у Yandex: `imap.yandex.ru`) |
| `MAIL_IMAP_PORT` | `993` |
| `MAIL_USER` | `support@pinposy.com` |
| `MAIL_PASS` | пароль ящика (лучше «пароль приложения», если провайдер их выдаёт) |
| `MAIL_SMTP_HOST` | `smtp.beget.com` (Yandex: `smtp.yandex.ru`) |
| `MAIL_SMTP_PORT` | `465` |
| `MAIL_FROM` | `PinPosy <support@pinposy.com>` |

Точные хосты IMAP/SMTP — в справке вашего почтового провайдера.

## Что уже заменено в коде

- Адрес `d65gng532k@gmail.com` заменён на `support@pinposy.com` в Политике, Условиях, лендинге, документах для Pinterest и README.

## Замечание о доставляемости

Пока сайт на бесплатных тарифах, письма пользователям (подтверждение регистрации, сброс пароля — Этап 2)
тоже будут идти через этот ящик. Для лучшей доставляемости позже добавим DKIM (провайдер выдаёт ключ) —
сделаем на Этапе 2.
