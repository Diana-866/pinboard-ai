# План на 14 дней: PinPosy → российский сервер → заявка Pinterest Standard

Цель: за 14 дней довести сервис до подачи заявки на повышение Pinterest API с Trial до Standard.
Заявка подаётся **только в конце**, после полной доработки и переезда на российский сервер.

Контекст: пользователей и данных в базе нет — разворачиваем с нуля, переносить нечего.
Домен и почта остаются в Beget. Бюджет — не больше 3000 ₽/мес.

Правила отметок: `[x]` — проверено (тест прошёл / команда выполнена / сценарий пройден), с датой и SHA.
`[~]` — сделано, но не проверено вживую. Пусто — не начато.
Действия владельца — в `docs/USER_ACTIONS.md`, ссылка вида `UA-nnn`.

## Стек на сервере

```
Caddy (443, HTTPS)  →  статика фронтенда
                    →  /api  →  backend (Node, 3000)
backend             →  Supabase (self-hosted, PostgreSQL + Auth + Storage)
worker: публикации  →  Supabase
worker: удаление    →  Supabase
```

## Текущий статус

- В репозитории **нет** ни одного файла развёртывания (`Dockerfile`, `docker-compose`, `Caddyfile`) — дни 3–4 начинаются с нуля.
- Бэкенд запускается как `node index.js`, воркеры — отдельными процессами (`npm run worker`, `npm run worker:account-deletion`).
- Публикации в Pinterest Trial идут в песочницу. Реальный пин на реальной доске в Trial не появляется — это не обещание и не проверка.
