# Чек-лист запуска PinPosy

Короткий список того, что должно быть верно **до** приглашения первых пользователей. Пункты без галочки —
либо ещё не проверены, либо ждут действий владельца. Подробности — в `docs/READINESS.md` (оценка по
областям) и `docs/DEVLOG.md` (как проверялось).

## 1. Инфраструктура

- [ ] Новая база создана одной командой: `scripts/provision-environment.sh` → 157 миграций, проверка пройдена.
- [ ] Backend развёрнут, `GET /ready` → `{"ok":true}`.
- [ ] Воркеры запущены отдельно: расписание и удаление аккаунтов (`ACCOUNT_DELETION_WORKER_ENABLED=true` —
      без него удаление аккаунта отклоняется).
- [ ] Внешнее наблюдение включено: `scripts/status-watch.sh --interval 60 --webhook <адрес>` в cron или
      systemd; алерт приходит на почту/в мессенджер.
- [ ] Резервные копии: `scripts/backup-postgres.sh` по cron, копии вне провайдера, `KEEP_DAYS` ≥ 14.
- [ ] Проверка восстановления выполнена хотя бы один раз: `scripts/restore-verify.sh` → все проверки PASS.
- [ ] Изображения перенесены и ссылки переписаны (`scripts/copy-storage.js`, `scripts/rewrite-image-urls.js`),
      `PIN_IMAGE_PUBLIC_BASE_URL` задан.

## 2. Деньги

- [ ] Prodamus в боевом режиме, `GET /billing/health` → `demo:false`.
- [ ] Демо-платёж прошёл, кредиты зачислены, история списаний сходится с балансом.
- [ ] Возврат средств проверен на тестовой операции.
- [ ] Тарифы на экране соответствуют включённым в Prodamus.

## 3. Pinterest

- [ ] Приложение Pinterest в нужном статусе доступа, скоупы на публикацию выданы.
- [ ] Подключение аккаунта из интерфейса проходит, токены шифруются и обновляются.
- [ ] Один пин опубликован на тестовом аккаунте, запись в календаре отмечена выполненной.
- [ ] Отзыв доступа обработан: расписания не публикуют, пользователю показано состояние.

## 4. Почта

- [ ] SMTP настроен, `MAIL_*` заполнены реальными значениями (не заглушками).
- [ ] Письмо подтверждения доходит на mail.ru, yandex.ru и gmail, не в спам.
- [ ] SPF, DKIM, DMARC настроены для домена.
- [ ] Сброс пароля и повторная отправка подтверждения работают на боевом домене.

## 5. Код и данные

- [ ] `npm test` в backend — 1440 из 1440.
- [ ] `npm test` и `npm run build` во frontend — без ошибок.
- [ ] `scripts/bench-e2e.sh` и `scripts/bench-acceptance.sh` на staging — все проверки PASS.
- [ ] CI в GitHub запускается (сейчас блокирован на уровне аккаунта: `runner_id=0`).
- [ ] Миграции применены к той же базе, к которой подключён backend (историческая причина отказа прода).

## 6. Перед приглашением людей

- [ ] Пройден чек-лист приёмки (33 сценария, собран GPT) — минимум все P0.
- [ ] Юридические тексты: оферта, политика конфиденциальности, согласие на обработку — опубликованы.
- [ ] Экспорт и удаление аккаунта проверены на боевом контуре.
- [ ] Есть канал поддержки и понятный ответ на «письмо не пришло».

## Красные флаги: запускать нельзя, если

- `/ready` не 200 хотя бы у одного пользователя;
- Prodamus в демо-режиме, а тарифы видны;
- воркер удаления выключен, а кнопка удаления есть;
- резервная копия ни разу не восстанавливалась;
- письма не доходят или уходят в спам;
- публикация в Pinterest не проверена ни разу.
