# База данных PinPosy

Единый список SQL-миграций, их назначение, идемпотентность, зависимости и
точные команды применения находится в [`db/migrations/README.md`](../db/migrations/README.md).

## Кратко

- Каноническая последовательность: `001_baseline.sql` → `002`–`008` → `010`–`011`. Миграция `009_hardening.sql` отсутствует и не применяется: текущие атомарные миграции сохраняют `user_id TEXT`.
- Применяйте перечисленные файлы строго по порядку, по одному, с остановкой при первой ошибке.
- Архивные SQL-файлы не входят в последовательность новой установки.
- Перед любыми изменениями существующей базы сделайте резервную копию.
- Не применяйте полную цепочку поверх рабочей базы без предварительной проверки
  фактической схемы и согласованного плана миграции.

Для команд `psql -f`, описания каждого файла и требований к предыдущим шагам
см. `db/migrations/README.md`.
