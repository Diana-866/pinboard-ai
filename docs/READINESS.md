# PinPosy: готовность к запуску (оценка на 22.11.2026)

Проценты здесь — не ощущение, а расчёт: каждая область получает вес (насколько она важна для запуска)
и оценку 0–100 с указанием, на чём она основана. Итог — взвешенная сумма. Оценка меняется только
вместе с доказательством: появилась проверка — балл растёт, сломалось — падает.

## Как читать 68 %

- **Код и данные готовы на 90 %**: сервис целиком работает на чистой базе — это проверено, а не заявлено.
- **Оставшиеся 32 % — почти целиком внешние**: рабочая база, платежи, Pinterest-приложение, почта,
  панели провайдеров. Ни одну из этих вещей нельзя закрыть из кода.
- **Без действий владельца потолок — около 80 %**: код, стенд, бэкапы и документация дойдут до предела,
  но платящего пользователя без реального платежа и почты не будет.

## Правило обновления

Оценка пересматривается, когда появляется или теряется доказательство: прогон тестов, проверка на стенде,
реальный платёж, письмо, публикация. Изменение процента фиксируется в `docs/DEVLOG.md` с причиной.
